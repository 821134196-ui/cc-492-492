# 首箱放行系统（包装订单投产首件检验）

包装订单投产前登记客户稿件版次、刀模编号、纸张批次、印色、箱型与产线；
首箱完成后采集实测尺寸、条码扫描结果与六面照片，质检员据此决定**继续生产**
或**停机返工**。零第三方依赖，仅用 Python 3.11 标准库 + SQLite。

## 一键启动

```bash
python3 run.py              # 初始化 SQLite、播种演示数据并启动 Web（默认 :8000）
python3 run.py --fresh      # 清空 data/ 后重建并重新播种
FCA_PORT=8080 python3 run.py
```

打开 <http://127.0.0.1:8000/>，右上角可切换当前身份：

- 张操作 / 李操作（操作员，负责登记与采集，**不能批准自己的首箱**）
- 王检 / 陈检（质检员，放行或判停机返工）

## 演示数据（种子）

| 订单 | 场景 | 入口 |
|---|---|---|
| PO-2401 | 正常投产 → 首箱合格 → 王检放行 → 留样 A-01 | 看板 |
| PO-2402 | **错版**：A 版已放行留样，客户改版 B 后 A 版首箱结论失效、留样 A-02 封档只读；B 版首箱待裁决 | `/orders/2`、`/fa/2`（只读旧样）、`/fa/3`（待裁决） |
| PO-2403 | 长度 +6 mm 超差 → 停机返工 → 复测合格陈检放行、留样 A-04 | `/fa/4`（停机）、`/fa/5`（复测） |
| PO-2404 | 五项阻断合集：条码不可读、宽未测量、混用旧刀模、缺顶面照片、样箱破损 | `/fa/6` |

可现场演练：在 `/fa/3` 用张操作身份尝试放行（被拒），切换王检/陈检后放行；
在留样柜页尝试移动封档留样 A-02（被拒）。

## 业务规则（全部在 `app/services.py` 强制）

1. **版次失效**：登记新版次后，旧版次置 `superseded`，其全部首箱结论
   `conclusion_valid=0`，禁止补批/补采集；旧留样归档 `archived`，
   照片目录转文件系统只读，页面只读、禁止移位。
2. **留样唯一**：同一订单同一版次最多一份生效留样（DB 部分唯一索引）；
   生效柜位互斥；仅放行首箱可入柜。
3. **五类阻断**（出现任一不得放行，只能停机返工后复测）：
   条码不可读/不符、尺寸超差（±2 mm）、混用旧刀模（上机刀模 ≠ 版次刀模）、
   六面照片缺面、样箱破损。
4. **审批约束**：操作员不能批准自己的首箱；非质检员不能裁决；
   `approvals.fa_id` 唯一索引 + `BEGIN IMMEDIATE` 保证两名质检员并发放行时
   **仅一人成功**，后者收到“已有裁决”。
5. **返工复测**：判返工记录停机原因；复测以 `prev_fa_id` 成链，可多轮，
   版次失效后旧链禁止复测。

## 数据存放

- SQLite（版次、审批等结构化数据）：`data/fca.sqlite3`
- 客户稿件：`data/files/artwork/`；六面照片：`data/files/photos/fa_<id>/`
- 条码设备：`app/scanner.py` 的模拟接口（可读 / NO_READ / 他单错码三模式），
  接真实设备时替换该类即可，服务层不变。

## 界面

- 看板：订单卡、待裁决队列、停机记录；纸白 `#f7f4ec`、墨黑 `#1a1a1a`、
  少量印刷蓝 `#1558a8`，车间大屏可读。
- 首箱核对页：**六面展开图**布局（顶/左/正/右/背/底），缺面红色虚线占位；
  测量值与目标值并排，超差行显示「实测 / 目标 / 偏差 ±x mm」具体数值，
  而非只涂红色。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：版次变更失效与禁止补批、五项缺项/异常阻断（边界 ±2 mm）、
两质检员并发仅一人成功、操作员自批拒绝、留样唯一/柜位互斥/旧留样只读、
返工复测链。
