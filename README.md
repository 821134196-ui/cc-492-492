# 首箱留样看板（包装订单投产质量闸口）

包装订单正式投产前，操作员登记**客户稿件版次、刀模编号、纸张批次、印色、箱型、产线**；
首箱完成后采集**实测尺寸、条码扫描结果、六面照片、留样柜位**，质检员据此判定
**继续生产（放行）或停机返工**。换版后返工复测，旧版留样只读归档。

仅依赖 Python 3.10+ 标准库，SQLite 存版次与审批，本地文件存稿件与照片，扫码枪为模拟接口。

## 启动（单命令）

```bash
python3 app.py
# 打开 http://localhost:8000
```

首次启动自动建库并写入演示数据（`data/`）。参数：`--port`、`--no-seed`、`--db`、`--media`。
想恢复演示样例：删除 `data/` 后重新启动，或 `python3 -m app.seed`。

## 操作路径

1. **看板 `/`**：每个订单的生效版次、产线/箱型/印色、刀模与闸口状态。
2. **订单页**：查看稿件文件、登记换版（旧首箱结论立即失效）、投产登记；
   把"上机刀模编号"改成旧编号即可演示**混用旧刀模阻断**。
3. **投产页**：首箱/返工复测采集。先到**扫码枪页**排程"可读 / 不可读 NOREAD / 设备无响应"，
   再点"触发扫码"；取消勾选某一面模拟**照片缺面**，选"破损"模拟样箱破损。
4. **首箱核对页**：六面展开图（上/左/正/右/背/下），**测量值与目标值并排**，
   超差处直接显示 `实测 156.5mm，目标 150mm，偏差 +6.5mm，允许 ±2mm`，不是只涂红。
5. 质检员选择"继续生产"或"停机返工"（停机必须填原因/差异标注）。

## 业务规则（`app/services.py`）

- **五类阻断放行**：条码不可读、尺寸超差、混用旧刀模、照片缺面、样箱破损；
  采集缺项（尺寸/扫码/柜面/六面照片/完好状态）阻断提交。
- **操作员不能批准自己的首箱**；非质检员账号不能审批。
- **两名质检员同时放行仅一人成功**：
  - 同一首箱的放行由部分唯一索引 `unique_release_per_article` 兜底；
  - 同一订单同一版次仅一份留样，由 `samples.revision_id` 主键兜底；
  - 写事务统一 `BEGIN IMMEDIATE`，并发失败者返回 `APPROVAL_RACE` / `ALREADY_RELEASED`。
- **版次失效**：换版后旧版 `active=0`，旧首箱不能补批、旧登记不能再提交首箱，
  须按新版次重新登记；已入柜的旧留样保留在 `samples` 中，页面标"只读归档"，
  不提供任何修改/删除入口。
- **返工复测**：被判定停机的首箱不可改判，在同一投产登记下新增第 2、3… 次采集，
  停机原因与复测记录全程留痕。
- **留样柜位**：放行即写入 `samples.cabinet_slot`，看板与订单页可查。

## 目录

```
app.py            单命令入口
app/db.py         SQLite 表结构与唯一约束（竞态防护在数据库层）
app/services.py   业务规则：登记/采集/核对/审批/换版/留样只读
app/devices.py    模拟扫码枪（脚本队列：可读/NOREAD/脱机）
app/media.py      稿件与六面照片的本地文件存储（SVG 占位实拍）
app/web.py        http.server 看板与六面展开核对页（纸白/墨黑/印刷蓝）
app/seed.py       演示数据：错版归档、停机返工复测、超差待判
tests/            28 个测试（含并发审批竞态、HTTP 集成）
data/             factory.db + media/{artwork,photos}（运行后生成）
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：版次失效（旧首箱不可补批/旧登记不可提交/仅一个生效版次）、
缺项与五类阻断、操作员自批禁止、两名质检员并发放行竞态（真实线程）、
停机→返工复测→放行链路、旧留样换版后仍只读，以及核对页具体超差数值渲染。
